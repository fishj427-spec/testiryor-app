Приложение создано для глубокого освоения и оперативного закрепления учебного материала по курсу «Экономика». Включает 255 верифицированных вопросов, задачи с расчётами и формулы.

Режимы подготовки
• Контрольная: тест с выбором количества вопросов и лимита времени (или без него) для приближения к реальному экзамену.
• Репетиционный: прохождение всей базы вопросов с мгновенной проверкой каждого ответа.
• Список вопросов: справочник всех заданий с правильными ответами и фильтрацией по темам и задачам.
